# Peep Journey Game

web peep. quiero hacer una web para el videojuego, donde el fondo arranque con E7E8DA, luego aparezca el bosque en un barrido hacia arriba, luego se baja el rosa -segunda imagen- como nubes en una transición. Posterior empiezan a aparecer las particulas de luz que floten , luego se deslizan los dos arboles a los costados 06403C de abajo hacia arriba. Luego en un zoomde adentro en expansion en el centro el logo, debajo del logo van los botones,
